## 关键特性总结
```
┌─────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                        关键特性                                                      │
├─────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                     │
│  ⚡ 并发机制:                                                                                        │
│     • supervisor_tools 中并发调用多个 researcher_subgraph 实例                                        │
│     • researcher_tools 中并发执行多个工具调用 (搜索、MCP、API等)                                      │
│     • 通过 max_concurrent_research_units 控制研究实例并发数量                                        │
│     • 工具调用通过 asyncio.gather() 实现并行执行                                                    │
│                                                                                                     │
│  🔄 循环机制:                                                                                        │
│     • supervisor ↔ supervisor_tools: 多轮研究规划                                                    │
│     • researcher ↔ researcher_tools: 多轮工具调用                                                    │
│     • 通过 max_researcher_iterations 和 max_react_tool_calls 控制循环次数                           │
│                                                                                                     │
│  🏗️ 分层架构:                                                                                        │
│     • 主图: 整体流程控制                                                                             │
│     • 子图: 具体功能实现                                                                             │
│     • 节点: 单一职责执行                                                                             │
│                                                                                                     │
│  🛡️ 安全机制:                                                                                        │
│     • 循环次数限制                                                                                   │
│     • 并发数量限制                                                                                   │
│     • 错误处理和重试机制                                                                             │
│                                                                                                     │
└─────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
